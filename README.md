# 🌐 Web Programming & Basic Web Applications

HTML, JavaScript, AJAX 등 웹 프론트엔드 기본 기술을 학습하고, 이를 활용하여 미니 프로젝트(영화 사이트, Todo-List)를 구현한 내용을 기록하는 공간입니다.

---

## 🛠 개발 환경 및 기술 스택

* **Languages**: HTML5, CSS3, JavaScript (ES6+)
* **Techniques**: Asynchronous JavaScript (AJAX / Fetch API, XMLHttpRequest)
* **IDE**: VS Code / Eclipse

---

## 📅 주요 학습 및 구현 내용

| 구분 | 주요 학습 주제 | 핵심 설명 및 구현 기능 |
| :---: | :--- | :--- |
| **HTML & CSS** | **웹 시멘틱 태그 및 구조 설계** | • Web 표준 문서 구조 작성 및 DOM 요소 배치 |
| **JavaScript** | **동적 UI 제어 및 이벤트 처리** | • 이벤트 리스너(Event Listener), DOM 조작, 기본 제어문 및 객체 활용 |
| **AJAX** | **비동기 데이터 통신** | • 페이지 새로고침 없이 외부/내부 API 데이터 요청 및 응답 처리 |
| **Project 1** | **간단한 영화 사이트** | • 영화 API(또는 JSON 데이터)를 호출하여 영화 목록/정보를 비동기적으로 바인딩 및 표시 |
| **Project 2** | **Todo-List 앱** | •할 일 추가, 완료 체크, 삭제 등 기본적인 CRUD 동작 및 동적 DOM 렌더링 구현 |
